# Demo and screenshot guide

1. READMEに従って拡張機能を読み込み、「ファイルのURLへのアクセスを許可」をオンにする。
2. オプションに**架空の**プロフィールを入力する。JevとローカルLLMはオフにする。
3. `examples/demo-form.html` をChromeで開き、拡張機能から「現在のフォームを解析」を実行する。
4. プレビューに候補と確度が出た状態、または選択して入力した状態を撮影する。必ず候補と入力値が架空であることを確認する。

現時点ではこのrepositoryに実画面のスクリーンショットはありません。画像を追加する場合は、撮影した実画面だけを掲載し、Chromeプロフィール、URLバー、通知、実在する連絡先を写さないでください。通常の応募フォームでは実施しないでください。
